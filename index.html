Simpan

Pengaturan disimpan di browser ini.

Menyambungkan sensor

  1. Nyalakan ESP32 sensor. Jika belum ada WiFi, sambungkan HP ke hotspot esp selada keriting, lalu buka 192.168.4.1.
  2. Pilih WiFi rumah atau hotspot, lalu simpan.
  3. ESP32 mengirim data ke Firebase tiap 1 detik.
  4. Buka Pengaturan di dashboard ini dan pastikan URL Firebase benar.

Menyambungkan kamera

  1. Sambungkan ke WiFi ESP32-CAM-SELADA dan buka 192.168.4.1.
  2. Isi SSID dan password WiFi, lalu catat IP yang muncul.
  3. Masukkan IP itu di Pengaturan, lalu buka menu Kamera.
  4. Jika dashboard dibuka lewat https, browser memblokir stream http. Buka file ini langsung dari komputer.

Catatan penting

  1. Kode ESP32 memakai POST, sehingga Firebase membuat satu catatan baru tiap detik dan database akan terus membesar. Pertimbangkan PUT untuk data terbaru, atau kirim tiap beberapa detik.
  2. Aturan database Firebase harus mengizinkan baca untuk dashboard ini.
